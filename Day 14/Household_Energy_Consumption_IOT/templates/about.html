Household Energy Consumption Forecaster

An intelligent web application that predicts household energy consumption using Machine Learning and provides interactive analytics for efficient energy management.

Machine Learning

Gradient Boosting Regressor is used to predict household energy consumption.

Backend

Flask framework is used to handle routing, authentication and prediction.

Database

SQLite database stores users and prediction history securely.


Frontend

HTML, CSS and Bootstrap are used to create a responsive and professional user interface.

Future Scope

Integration with IoT devices and ESP32 sensors for real-time energy monitoring and forecasting.
